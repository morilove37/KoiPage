# 游玩足迹分享 Implementation Plan

**Goal:** 生成可筛选排序的游玩足迹图片，并支持 24 小时公开链接。
**Architecture:** 纯函数选择集合，Canvas 生成相同预览/导出图，原生读封面、写文件及上传；原生剪贴板插件复制图片和链接。
**Tech Stack:** React / TypeScript / Canvas / Tauri / Rust / reqwest multipart。
**Spec:** ../specs/2026-10-16-game-sharing.md

## Global Constraints

保留现有首页改动；不修改游戏资料。统一使用用户附件作为替换封面。公开链接匿名到期时间为 24 小时；仅显式上传 PNG。默认每页 60 部；多页完整导出，不截断。日常使用开发版，不生成安装包。

## Review Focus

隐藏游戏不得进入海报与统计；替换封面不加载原图；乱序/null 值；编辑期间的旧预览/旧链接；网络失败与多页部分成功；本地图片 CORS；文件及 PNG 大小限制。

## Tasks

- [x] 1. model.ts 与测试：游玩判定、排序、隐藏与分页。
- [x] 2. PNG 渲染与原生支持：封面读取、保存、24h 上传和剪贴板；接口契约及 Rust 测试。
- [x] 3. 分享编辑/预览与游戏库入口：配置、隐藏、替换、导出状态与错误处理。
- [x] 4. 浏览器交互、图片视觉检查、开发版真实本地封面与虚构资料的上传验证；记录限制。

## Execution record

Ruling: Litterbox 的实际上传返回 412/403，改用已验证匿名上传成功的 beacon.host。采用文件清单、预签名存储上传、最终发布三阶段；同一网页包含全部分享图，避免多页消耗多次发布限额。只返回查看链接，管理令牌不暴露给网页或分享接收者。失败保持本地图片操作。

验证结果：5 项分享纯函数测试；68 项 Rust 测试通过（13 项外网测试按既有规则忽略）；43 个 IPC 命令契约一致；前端构建通过。浏览器验证隐藏、替换、排序、上传失败重试、旧链接清理及 61 部作品分页/全量保存。开发版真实本地封面保存与 UI 图片复制通过。开发版上传纯测试画布组成的两页相册成功，匿名访问 HTML 与两张 PNG 均为 200；真实游戏资料未公开上传。
