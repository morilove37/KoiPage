# 资料焕新与 Bangumi ID 补全

用户要求在设置加入带警告的一键焕新，并要求启用 Bangumi 时，新游戏导入和焕新都补齐 Bangumi ID，不受默认源影响。

- 共用解析器在启用 Bangumi 且缺少 ID 时请求 Bangumi；仅接受唯一精确匹配，核对发行日期与已知外部 ID。借用简介时保留确认过的 ID。已有绑定不覆盖。
- 设置提供明确覆盖警告和确认框。后台串行任务开始前创建完整资料备份，备份失败不更新；支持进度、停止、结果及重新执行，导航不丢任务。
- 更新当前语言规则下的名称、原名、开发商、发行日、公共评分和简介，中文简介优先，同语言优先默认源。缺失资料不清空，已有中文不退回英文。标签合并。
- 保留路径、封面、游玩状态与时间、笔记、存档、个人评分和评论、已有外部 ID。每款写入一个事务，网络期间发生资料修改则跳过。匹配有歧义不写入。
- 批次持有 Bangumi 同步锁，避免新增绑定在批次中途同步，结束后标记待同步。
- 测试仅用内存数据库和本地测试数据，不在用户真实库执行焕新。执行前端测试与构建、Rust 测试与开发构建、IPC 检查，最后正常开发运行。
