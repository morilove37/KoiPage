# 内置 LunaTranslator

用户要求将 Luna 翻译器整合到实用工具，前提是作者允许使用；已选择「直接随恋页内置，安装后离线可用」。官方 LICENSE 为 GPLv3，核实官方仓库和文档后采用独立进程调用，保留程序、许可和对应源码，不改变 Luna 二进制。

- 内置官方 x64 v12.1.2.9 原始 ZIP，SHA256 1d8a2fd8ec0aade868471e0976491d2e97888d38f14d909f0e7628b9442410a3。附带 commit 5a11c55e2cc8c0095a77f9f2145eb01bd6cfc410 完整源码 ZIP、GPL 与 NOTICE；原包 LICENSES 原样保留。
- Rust include_bytes 嵌入压缩包和源码，借助已有内置 7-Zip 离线释放到 app_local_data_dir/tools/luna/12.1.2.9/LunaTranslator_x64。工作目录设为该程序目录；只启动普通 LunaTranslator.exe，不主动提权或注入游戏。
- 首次释放先解压至临时目录，再完整发布文件，避免中断后留下截断 DLL；成功部署后的修复只补缺失/空文件，保留 userconfig、缓存、自更新过的文件；最后写就绪标记，常规查询校验关键文件（含 main.py 与 python3.dll）。固定源码和许可副本按内容验证并原子修复。并发准备与启动需加锁。后台阻塞任务执行释放，不阻塞 UI。
- 实用工具增加「游戏翻译」卡片和左侧导航项，显示内置版本、就绪/运行状态，支持启动、重新检查、打开目录、官方教程、项目/许可/源码入口。首次准备失败可重试，错误只影响本卡片。
- 用户补充退出需求后增加「退出 Luna」：只选择该内置路径对应 PID 的 Luna Qt 窗口，正常 WM_CLOSE 触发来源程序保存退出，不强杀，不重新部署。等待最多 5 秒确认退出，更新页面状态；未运行时禁用按钮，未完成退出时显示处理提示。
- 提供默认关闭的「随游戏启动」，只启动翻译器本身，文本提取、翻译接口和游戏绑定在 Luna 中配置；启动失败不阻止游戏。
- 说明「内置程序可离线启动；在线接口需要网络，本地翻译需自行配置离线引擎」。不修改用户翻译设置、密钥，不运行管理员入口，不强杀外部进程。
- 验证原包及源码校验和、离线释放、重复释放保留设置/自更新、缺件重试、启动工作目录和并发。运行前端构建、IPC 检查、Rust 测试，开发版验证真实启动状态和界面。日常工作不生成安装包。
