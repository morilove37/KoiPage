# 确认界面自由选择简介来源

用户要求有多个简介来源时可以自由切换，并补充要求自动选择默认数据源。保留安全确认属于同一作品的非空简介（含源、语言、署名），手动确认时加载所有已启用可匹配来源，在简介来源下拉框切换并立即更新预览、最终提交值。用户进一步明确中文优先：初始优先中文简介，中文版本中再优先默认数据源；默认 VNDB 只有英文时选其他来源中文，没有中文时才按默认源与原回退规则选择；只有一份时维持简洁展示。切换不改变其他资料字段或「简介」勾选状态；已有记录的简介保护继续有效。

采用扩展详情响应的方案，不新增数据库表。备选是前端重新逐源查询，容易导致身份校验与导入路径分叉；本次复用服务端匹配规则。手动确认请求显式开启多简介收集；自动补全和批量导入保留原有回退和请求量。其他来源并行且逐源超时，失败不影响已取得的简介。重新选择作品、关闭再打开时清除上次的简介选择。

验证只使用纯函数测试、临时数据与只读预览；不向用户库写入测试记录。不打安装包。
