# VNDB 导入时补充其他来源简介

用户要求选择 VNDB 时同时导入其他来源的简介。本次采用自动补充方案：VNDB 仍是主条目，其他已启用来源提供中文简介，确认页显示简介来源，已有简介仍受字段保护规则约束。

先通过已有 NextMoe 外部 ID 反查补充；VNDB 结果仍没有中文简介时依次尝试启用的 Bangumi、2DFan。直接搜索必须是唯一的规范化标题精确匹配，且已知外部 ID / 发售日期不能冲突；存在歧义则跳过。所有来源失败均保留主结果，不写入数据库。已有中文简介不被较低优先级来源替换，空简介不能覆盖有效内容。补充搜索只取一组结果，按日文原名、源标题、中文名选择一个查询，保持有限请求量。

备选方案是仅修正 NextMoe 合并规则，覆盖面不足；或新增逐字段多源选择器，交互范围较大。本次保持现有确认流程，中文简介优先并明确显示来源。

验证使用离线数据与网络只读查询，不向实际用户库写入测试记录。不修改已发布数据库迁移，不发布安装包。
