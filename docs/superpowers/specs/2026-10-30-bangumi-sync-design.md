# Bangumi 双向自动同步

用户明确要求双向自动同步、个人令牌放在设置。本次实现设置连接/断开与自动开关、默认两分钟轮询和本地更改后触发、已绑定 Bangumi ID 作品的状态/独立个人评分/独立短评双向同步、冲突处理及逐款暂停。未绑定作品提示补充 ID，不按名字自动绑定，也不自动新建远端独有作品的本地条目。

个人令牌仅保存在 Windows 用户凭据管理器，前端只能写入与查看是否连接，不返回令牌；不进入数据库、日志、JSON/完整备份。保存令牌先 GET /v0/me 验证，再存储；换账号/断开后自动同步关闭，显式开启时说明哪些字段将上传。新建收藏默认仅自己可见，可在设置调整；更新已有收藏不修改其隐私或标签。

同步状态：想玩→1，已通关→2，游玩中→3，搁置→4，弃坑→5。未游玩没有对应远端状态，不自动上传或删除远端收藏。新增独立我的评分（0-10 整数，0 未评分）与 Bangumi 短评；现有公共评分、私人备注和元数据标签不上传。

使用每个账号/作品最后成功快照做逐字段三方合并：单边变化传播，两边不同变化标记冲突，相同变化直接确认。首次双侧有不同非空值时冲突，不靠 updated_at 判断（官方说明其不可靠）。远端删除收藏形成冲突，不自动重建。冲突支持保留本地/采用 Bangumi；不能上传未游玩状态时提示调整或暂停。

服务端锁防止重复运行；比较本地保存版本与读取值，保留同步期间的新编辑；上传前再次检查远端，上传后读取确认，失败不推进基线。认证失效暂停同步；限流不立即重试。所有真实账号写入只会在用户输入令牌并显式开启或点击同步后发生；验证只使用临时数据库及本地假 API，不向真实账户写测试数据。

备份含同步设置及个人记录，不含令牌；恢复备份后自动同步关闭，需要重新开启。

## 备选
仅导入或单向上传不能满足用户要求。按更新时间覆盖不可靠。本次采用自动三方合并、冲突暂停，主 UI 沿用现有设置与游戏详情。
