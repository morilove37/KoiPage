# 恋页 0.6.3：可靠性与日常管理

用户已明确授权按前次方案的第一、第二轮实现，并构建 0.6.3；不实现第三轮，不创建或发布 GitHub Release，不推送版本标签。

## 范围与验收

1. 完整备份包含一致性数据库快照、受管理封面、生日头像和本地背景等实际引用图片，附版本、计数、清单和 SHA-256。恢复先验证并预览，再备份当前数据，安全恢复；失败保留原库。禁止运行游戏时恢复。不包含游戏本体及游戏存档。
2. 会话周期保存已确认时长；启动检查遗留会话，不将停机时间算入时长。提供会话补记、修正、删除，使累计时长和统计一致。退出管理器时明确仍有游戏运行的处理方式。
3. 检查游戏目录和启动文件，区分缺失与离线；支持旧根目录到新根目录的映射，按目录边界替换安装路径、启动程序、工作目录及适用存档路径。先预览验证再事务提交，不搬动文件、不更改游戏 ID 或游玩历史。
4. 单款转区、Magpie、Luna 使用跟随全局/启用/禁用。允许单款缩放模式覆盖。实际启动流程及启动确认界面使用有效配置。
5. 多选批量修改状态、收藏和增删标签，事务处理。保留筛选、排序和视图偏好；详情返回恢复滚动。增加最近添加排序，允许保存/应用常用筛选。
6. CI 自动发现全部前端测试，继续执行构建、IPC、发布校验、Rust 离线测试。
7. 版本统一为 0.6.3。版本公告整合 0.6.2，文字精简；抖音昵称为“女友为了我变成4i”，号为“shuiwuyueying.”，链接使用用户指定主页。公告和设置共享这些信息。
8. 根 LICENSE 采用 GPL-3.0-only 正文，README、package/Cargo 元信息及设置同步。第三方内容保留各自声明。构建 EXE/MSI、签名（本地密钥可用时）并放入独立 0.6.3 待确认目录，记录校验值。禁止公开发布。

## 约束

保留当前未提交的 0.6.2 改动、数据标识和 MSI UpgradeCode。新增迁移，不修改已发布迁移。测试使用临时数据，不覆盖用户库。当前工作分支已有修改，沿用当前工作区并保存快照，避免隔离操作遗漏未提交资产。

## 模块边界

备份恢复、会话恢复、库批量管理可独立开发；新增后端模块、前端模块及测试，集中注册命令和迁移。路径与启动配置采用单独模块，避免继续扩大详情和设置主文件。恢复必须验证归档路径、图片和数据库；任何自动回退不得依赖当前会话内存。
