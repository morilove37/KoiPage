# 图标与角色来源

恋页 KoiPage v0.3.0 的图标使用《天津罪／アマツツミ》角色 **水无月萤（水無月ほたる）** 的 Q 版再创作头像。原作及角色归属 Purple software；本项目与原作官方无隶属关系。

- [原作官网与角色入口](https://www.purplesoftware.jp/products/amatsutsumi/index.html#ch)
- [月幕 Galgame 角色资料](https://www.ymgal.games/ca69231)
- [外观参考资料](https://www.animecharactersdatabase.com/jp/characters.php?id=76989)

图标由内置图像生成工具根据角色参考重新绘制，未将原作立绘直接打包为应用图标。

## 设计说明

采用头肩构图、较大的头部与清晰轮廓，保留棕色短发、蓝眼睛、呆毛、红色发带，以及白色上衣、深色水手领和红色领巾。使用简化赛璐璐阴影与紫色圆角底，适应桌面、任务栏和导航栏的小尺寸显示。圆角之外保留透明度。

## 生成提示词

以水无月萤的角色图为身份和服装参考，重新绘制可爱、健康的大头 Q 版头肩头像；棕色短发、一根弧形呆毛、侧后方红色发带、明亮蓝眼睛、白色水手服、双白边深色领口与红色领巾。双眼睁开、轻微微笑，简洁粗轮廓、少量平涂色块和简化阴影，脸部占主要面积；紫色圆角底、角外透明，保留安全边距，不加文字、水印或复杂背景。
