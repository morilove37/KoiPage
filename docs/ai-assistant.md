# AI 助手

在「设置 → AI 助手」填写 API 地址、模型 ID 和 API Key，点击「测试连接与工具调用」，成功后保存。左侧底部的「AI 助手」打开对话面板，切换页面时保留对话。拖动面板左边缘可自由调整宽度，双击该边缘或聚焦后按 Home 恢复默认；宽度会被记住。

- 第一版使用兼容 Chat Completions 的 `/chat/completions` 协议，模型须支持 function tools。地址填写服务商提供的基础地址（通常包含 `/v1`），也接受完整请求地址。仅支持 OpenAI 兼容接口；Anthropic Messages 等原生协议端点（地址常含 `/anthropic`）不能填入此处。
- 远程服务使用 HTTPS。本机 `localhost`、`127.0.0.1` 和 IPv6 回环服务可用 HTTP，免密本机服务可留空 API Key。
- 密钥按 API 地址分别存入当前 Windows 用户的凭据管理器；设置页不会读回原文，输入框留空保存会保留对应地址已有的密钥。切换服务不会把原服务的密钥发送给新服务。可用「清除已保存密钥」删除当前地址的凭据。
- 面板底部显示本次对话的 token 用量（输入、输出、合计；服务端返回时还显示缓存命中数），「清空对话」会同时重置统计。费用可选：在设置中按所用服务商的「输入/输出价格（元/百万 tokens）」填写后，会按统一单价换算成估算费用，留空只显示 token。缓存折扣、阶梯计价等以服务商账单为准，估算仅供参考。价格设置保存在本机，与 API 密钥分开。
- 密钥不包含在游戏库备份中。迁移电脑后需重新填写。对话保存在内存中，关闭软件后清空。
- 对话历史不设应用侧轮数或体积上限，完整历史会发送给模型。超出模型自身上下文时由服务端返回错误，服务端给出的原因会显示在面板中；需要重新开始时点「清空对话」。

## 支持的操作

搜索、筛选、排序和分页查询游戏，读取游戏资料及标签，统计游戏库；修改标题、原名、开发商、发售日期、评分、简介、游玩状态、收藏标记和追加标签；打开详情；按已有启动配置启动游戏（需要在面板确认）。面板中的操作记录会显示对应的游戏名或搜索词，便于核对。

根据明确指令直接保存资料，无需逐次确认。例如要求「翻译简介并替换」时，AI 可读取全文、翻译并直接保存到游戏资料。简介每次读取最多 8,000 字符，可顺序继续读取到完整原文；未读完整或原文已变更时拒绝覆盖，需继续读取或重新读取。新简介最多 30,000 字符。日期必须为有效的 YYYY-MM-DD 格式，评分为 0–10；可用 null 清空可选字段，标题不能为空。

示例：

- 找出未游玩的游戏，按评分排序。
- 把《游戏名》设为已通关，并添加「收藏」标签。
- 把《游戏名》的简介翻译成简体中文并替换，保留人名和段落。
- 把《游戏名》的开发商改为「制作组名」，评分改为 8.5。
- 打开《游戏名》的详情。
- 启动《游戏名》。

AI 必须先查询目标，使用查询结果里的游戏 ID 才能操作。此版本没有删除、任意文件读写、终端执行、恢复存档或修改启动命令的工具。单次任务不设应用侧轮数或单次工具调用数上限，会持续执行到模型给出最终回复；可随时点「停止」中断（已完成的操作会保留，未执行的调用标记为已取消）。

工具结果仅提供完成任务所需的资料，不包含游戏的本地路径、私人笔记和密钥。用户输入、查询到的标题、开发商、评分、游玩状态、时长等资料，以及按需读取的简介和标签会发送给所配置的 API 服务，费用及数据处理方式取决于该服务。

「停止后续操作」会取消网络请求并阻止尚未开始的操作；已送达软件并完成的修改会保留。关闭面板也会停止后续操作。工具执行记录独立于模型文字，失败的详细诊断仅显示在本机，不会作为工具错误发送给模型。

## 连接排查

401/403：检查密钥与模型权限。404：检查基础地址的版本路径和模型名称。429：检查余额或调用频率。模型仅回复普通文字、没有正确调用测试工具时，连接测试会提示工具调用不兼容。请求不跟随 HTTP 重定向，应直接填写最终服务地址。接口返回错误时，设置页会附带服务端返回的错误信息（截取 200 字），便于判断模型能力、余额或地址问题。

协议实现参考 [官方 Function calling 文档](https://developers.openai.com/api/docs/guides/function-calling)。
