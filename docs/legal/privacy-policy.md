# 恋页隐私政策

版本：2026-11-13.1

更新及生效日期：2026 年 11 月 13 日

## 一、适用范围与选择权

本政策适用于恋页 KoiPage Windows 客户端及开发者提供的好友邀请内测服务。恋页用于管理本机已有游戏，不提供游戏本体下载。我们将本地管理与可选联网功能分开：不注册好友账号、不接受好友服务的个人信息出境处理，也可以使用本地游戏库、启动、游玩记录和本地备份。

注册前请阅读《好友内测服务协议》《个人信息出境告知与单独同意》和《第三方服务与数据处理清单》。注册页的同意不自动开启正在游玩分享、游戏库分享、Bangumi 同步或临时链接发布；这些功能需要你另外操作。

## 二、本地保存的信息

游戏库、作品资料、游戏及存档路径、启动配置、标签、私人备注、个人评分、游玩记录、主题和其他设置，主要保存在本机应用数据目录。封面、自定义图片、备份和存档快照保存在本机或你选择的位置。扫描和进程跟踪用于导入游戏、启动及统计恋页跟踪的游戏时长；好友服务不上传进程清单。

恋页不会仅因启动本地管理功能就将完整游戏库上传给开发者。本地备份、导出文件可能含有私人记录或路径，请自行保管。本地诊断日志用于排错，可能包含时间、错误及相关文件或作品信息；请在导出、发送前检查。导出日志本身不会自动发送给开发者。

## 三、好友账号与必要联网处理

- 注册及登录：处理用户名、昵称、邀请码、密码、账号标识、好友码及登录会话。注册使用系统生成的内部账号标识，不要求提供真实邮箱或手机号码。密码通过 HTTPS 交给托管认证服务验证；恋页不会在本地普通数据库中保存明文密码。会话令牌保存在当前 Windows 用户的凭据管理器中。
- 防止注册滥用：托管入口读取注册请求的公网 IP，服务端用随机秘密盐生成规范化 IP 摘要，记录成功注册情况，以执行每个公网 IP 只能注册一次的限制。业务表不保存明文注册 IP；托管平台仍可能处理网络 IP 和访问日志。该摘要属于去标识化处理，不将其宣称为彻底匿名化。
- 好友关系：保存好友申请、已建立的好友关系、屏蔽关系和处理状态。添加好友或处理申请时，对方可看到必要的用户名、昵称、预设头像和好友身份信息。
- 在线状态：登录并连接好友服务后发送在线心跳；好友可查看在线或离线。开启隐身会对好友显示离线。默认不分享正在玩的作品。
- 注册同意记录：成功创建账号时，服务端记录文档版本、服务协议同意、隐私政策同意、出境单独同意及服务端接收时间，用于证明本次注册的选择。不会据此推定你同意其他可选上传，也不为旧账号补写不存在的历史同意。

## 四、由你单独开启的分享

- 正在游玩：仅在开启相应开关后，向服务端发送恋页启动并跟踪的作品名称、可选资料源标识、本次游玩时长等状态，供好友查看。隐藏指定作品可排除该作。
- 游戏库：仅在开启“向好友公开我的游戏库”后，上传可见作品的名称、原名、制作商、游玩状态、个人评分、累计时长、可选资料源标识和重新编码的封面缩略图。公开封面进入私有审核区，NSFW 及分级未知的作品会打码；来源封面待审核时显示占位图，自定义封面作品审核前不向好友展示。不上传游戏目录、存档位置、启动参数、私人备注、游戏本体或存档文件。“公开”指对获准访问的好友可见，不是自动向所有互联网访客开放。
- 最近游玩：另行开启后上传最近的作品、开始和结束时间及记录时长，供好友查看最近 7 天。同步窗口保留最近 30 天，关闭并成功同步后清除远端记录。
- 举报及封面审核：处理举报时保存举报原因、说明及提交当时的作品和封面快照；审核候选保存确切缩略图、作品和审核状态，仅供服务端审核使用。换图或撤回分享不会替换已提交的举报证据，账号删除时清理关联举报和审核候选。
- 撤回：关闭分享、隐藏作品或删除及屏蔽好友，可限制后续访问或撤回对应云端资料。断网时撤回要等连接恢复后完成，请留意界面提示。隐身仅隐藏在线和当前作品，不会自动撤回已经分享的游戏库；普通关闭应用也不会立即撤回已分享收藏。
- 临时分享链接：保存或复制分享图片在本机完成；只有另行确认并生成链接，才把当前预览的全部分享图及展示页面上传到 beacon.host 和其存储服务。拿到链接的人可访问，可能涉及境外处理，不限于好友。链接约 24 小时失效；恋页目前不提供提前撤销入口，也不能追回他人已经保存、截图或转发的内容。分享图请勿包含真实身份、敏感隐私、他人个人信息或不适合公开的内容。

## 五、资料源、同步、翻译与更新

启用联网资料匹配时，会向你启用的 NextMoe、VNDB、Bangumi、2DFan 等资料源发送搜索名称、作品标识或必要查询参数，并下载资料和远程图片。请求可能由自动补全触发；对方能够接收请求 IP、客户端请求头和查询内容。可在设置调整启用范围，或使用手动填写及本地图片。

Bangumi 双向同步仅在你提供个人令牌并开启后运行，向 Bangumi 读写绑定作品的收藏状态、个人评分和短评等；新建收藏默认私密，已有收藏的隐私设置保持不变。私人备注、标签和存档不会作为同步字段上传。可停止同步并移除令牌。

内置 LunaTranslator 是独立运行的第三方程序。其获取的游戏文本、截图、语音及向在线翻译或 AI 服务发送的内容，取决于你在该工具中的配置；离线与联网方式有所不同。请在使用前阅读所选提供方规则，不向其发送个人隐私或无权提供的内容。

版本检查和安装包下载访问 GitHub 等发布服务；只有更新请求所需的信息会随网络请求发送，不上传完整游戏库。第三方服务的具体入口、目的和选择方式见《第三方服务与数据处理清单》。

## 六、委托处理、提供与公开

我们使用 Supabase 提供好友认证、数据库和接口托管，由其基础设施及必要的分包服务处理相关请求。新版连接通过 Cloudflare Workers 的 https://api.koipage.xyz 入口转发，Cloudflare 会处理公网 IP、请求头、注册登录信息、会话令牌及同步请求内容。注册 IP 由入口签名传递至后端验证，客户端自填 IP 不作为注册依据。应用层不缓存私人接口响应，不记录请求正文和令牌。好友数据库当前选择新加坡区域；网络接入、函数、日志、运维和基础设施可能涉及其他国家或地区，不能将“数据库位于新加坡”理解为全部处理仅发生在新加坡。旧版直连地址仍保留，不会把原有同意记录自动改成新版同意。详情及权利行使渠道见《个人信息出境告知与单独同意》。

我们不会出售你的个人信息，不会将游戏库用于广告画像。向好友提供资料、向第三方发布图片只在对应功能的范围内进行。依法应向有权机关提供时，我们将核实依据并控制必要范围。新增处理目的、种类或需要另行授权的接收方时，将更新告知并依法重新取得同意。

## 七、保存期限与删除

- 本地数据：由你通过应用操作或删除相应文件管理；卸载不必然删除所有应用数据、另存的备份、图片或游戏存档。
- 账号、好友关系及认证记录：在账号使用期间按服务所需保存；停用不等于注销。自助注销服务部署后，可在设置输入用户名并确认，服务端校验后删除认证账号并级联清理业务数据；服务不可用时可通过邮箱申请处理。网络中断不等于注销成功，会保留可重试状态及登录凭据；只在服务器确认完成后显示注销成功。完成查询摘要会解除账号关联，用于确认丢失的成功响应，不能用于登录或删除其他账号。
- 正在游玩状态：停止心跳后约 90 秒对好友失效，定时任务随后清理过期作品状态；网络或服务异常可能影响清理时间。这不等于基础设施日志也同时删除。
- 已分享收藏：在你关闭分享并成功撤回、隐藏或移除对应作品，或账号删除时，处理相应云端记录；离线期间可能暂时仍可见。
- 注册防滥用摘要：当前实现不会在账号删除时自动释放 IP 注册名额，该摘要及成功记录仍被保留。你可通过邮箱提出删除或保存必要性质疑，我们将核实处理；它不会自动赋予开发者无限期保存的权利。
- 同意记录与申请往来：仅在提供服务、履行法定义务或处理争议所必要的范围和期限内保留；账号删除时不会凭空另建永久留存副本。依法需要继续保存的部分会限制其他用途并告知原因。
- 托管日志、缓存和备份：受第三方服务的实际生命周期影响，删除业务记录不代表所有底层副本即时抹除。我们会在能力和合同范围内推进删除或限制处理，不承诺尚未核实的统一删除天数。

## 八、查阅、更正、复制、撤回和注销

你可以在应用中修改昵称、头像、分享开关、隐藏作品及好友关系；本地资料可以编辑、备份或导出。如需查阅、复制云端个人信息、撤回注册时的出境同意、注销账号、删除数据或投诉，请发送邮件至 3375482795@qq.com，建议主题为“恋页隐私申请”，说明用户名及希望处理的事项。

我们只会要求与核验账号控制权相称的信息，不会要求提供明文密码、登录令牌、完整游戏库或无关身份证件。收到申请后先确认并说明必要的核验、处理范围和预计安排；不能满足的将说明原因。出境处理是当前好友后台运行的必要条件，撤回后需停止相应联网服务并申请处理既有数据，本地管理仍可使用。撤回不影响此前基于有效同意的处理。

## 九、安全和未成年人

我们采用 HTTPS、服务端访问控制、受限好友访问和本机凭据存储等措施，并在发现安全事件时采取补救、依法履行通知等义务。任何措施都不能保证绝对安全，请保护设备、密码、备份和分享链接。

如果你是未成年人，请与监护人共同阅读并依法取得必要同意。当前邀请内测暂不提供不满十四周岁用户的自主注册及监护人授权流程；不满十四周岁请勿自行注册，请由监护人联系上述邮箱。如发现未经有效监护人同意处理其信息，我们将核实并采取停止处理、删除等措施。本地工具及分享内容也不得用于侵害未成年人权益。

## 十、政策更新

文档随应用提供，可在好友页、设置“关于恋页”查看并复制保存。涉及处理目的、方式、信息种类、出境等实质变化时，我们将显著告知，并依法重新征得必要同意；不会用“继续使用即同意”替代依法应当取得的明确或单独同意。
