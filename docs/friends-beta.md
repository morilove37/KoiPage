# 好友 Beta 使用说明

好友功能连接官方在线服务。无需邀请码注册，每个公网 IP 累计最多注册 5 个账号；共用出口的家庭、校园或运营商用户可能共用名额。已有账号登录不受注册名额影响。

## 注册、登录与添加好友

在侧栏打开「好友」，填写用户名、昵称和密码。注册前阅读并主动同意当前版本的服务协议、隐私政策和个人信息出境告知；不注册仍可使用本机管理功能。用户名为 3–32 位英文字母、数字或下划线；密码为 12–72 位可见英文字符，不支持中文和空格。

登录后可复制好友码、发送好友申请、选择角色头像、查看好友主页。游戏库和最近游玩记录由独立分享开关控制，默认关闭；分享范围以当前界面与隐私政策为准。隐身、隐藏作品、删除或屏蔽好友均可在客户端操作。

## 数据与账号安全

好友页面展示双方主动分享的资料与受限缩略图，不接收或执行好友电脑上的程序。游戏目录、存档位置、启动参数、进程 ID、私人备注和游戏本体不属于好友分享内容。登录令牌保存在当前 Windows 用户凭据管理器，不进入普通游戏库备份。

账号可在「设置 → 账号注销」中自助注销。注销删除在线账号及相关服务数据，不删除本机游戏库、游戏文件或存档。网络中断时按界面提示重试确认；忘记密码、注销异常或安全问题可联系开发者。
