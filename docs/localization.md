# 标签离线汉化

入口：**设置 → 资料汉化 → 标签离线汉化**。

## 如何工作

应用内置 `src/lib/tag-translations.json`，包含 567 条标签译名。游戏库、首页、详情、标签管理和资料导入预览共用这份词典，不发起在线翻译请求，也不需要翻译密钥。

匹配前会规范化大小写、空白、全角字符、弯引号和常见连接号，然后精确查表。未收录的标签保留原始名称，不进行模糊猜测。

汉化只影响显示：

- 不修改数据库里的标签名称、ID、关联或游戏资料。
- 筛选和标签定位继续使用原始 ID。
- 导入预览显示中文标签，确认保存时保留数据源原始名称。
- 游戏简介始终保留原文。
- 关闭开关立即恢复原始标签显示。

## 与旧版的兼容

继续使用 `metadata_localization_enabled` 设置键，保留原有开关状态，新用户默认关闭。

旧版在线翻译缓存不再读取；既有数据库迁移保留，升级时不会重建游戏库。

## 扩充词典

在 `src/lib/tag-translations.json` 增加小写的原始标签和简体中文译名。优先使用准确、简洁且含义一致的译名；保留不同原始标签的 ID，即使它们显示为相同中文也不合并数据。
