## 恋页 KoiPage v0.7.3

QQ 群：1055772679。加群前请阅读群介绍并回答入群问题，推荐使用手机 QQ。

本次为 0.7.3 修订版，内部更新版本码为 0.7.3003，已安装原 0.7.3 的用户也可升级并重新查看公告。

本次更新加入 AI 助手与社团 Logo，让整理游戏库更方便；同时调整好友服务的访问入口与注册规则，并补充备份、全屏和界面体验的修正。以下为相较于 v0.7.2 的更新内容。

### AI 助手，帮你整理游戏库

- 新增「设置 → AI 助手」，支持配置兼容接口的 API 地址、模型与密钥，并测试连接和工具调用能力；需要自行提供支持工具调用的模型服务。
- 从侧栏打开对话面板，可用自然语言搜索游戏、查看资料、统计游戏库、打开详情，以及修改标题、开发商、日期、评分、简介、游玩状态、收藏和标签。
- 支持读取游戏简介并翻译替换；启动游戏前需在面板确认。工具执行过程可查看，也可停止后续操作。
- API 密钥保存在 Windows 凭据管理器，不随游戏库备份导出。对话仅在本次运行期间保留；使用时会将相关问题与所需游戏资料发送到你配置的服务，请留意其费用及数据处理规则。
- 连接测试兼容 DeepSeek 等思考模型；接口报错时显示服务端返回的错误信息，便于排查地址、密钥或模型权限问题。

### 社团分类，有了自己的 Logo

- 游戏库社团分类文件夹支持自动获取并缓存 Logo，缺少图片时保留默认文件夹图标。
- 右键社团文件夹可设置自定义图片、重新获取 Logo 或恢复自动获取，并查看图片来源。
- 社团 Logo 纳入数据备份与恢复，迁移后同步修复图片引用。

### 减少后台联网请求

- 好友列表改为每 30 秒刷新，个人主页每 60 秒刷新；空闲 5 分钟后降为每 2 分钟，隐藏或失去焦点时暂停页面轮询，恢复使用后刷新。
- 在线心跳前台每分钟一次，后台或空闲每 5 分钟一次；正在分享游玩状态时保持每分钟一次，作品和隐私变化仍及时上报。
- 降低后台游戏库与游玩记录自动检查频率；配套延长在线过期宽限至 7 分钟，异常退出后的离线显示可能相应延迟。

### 好友服务迁移至香港自托管

- 账号认证、好友接口与数据库迁移到香港服务器，正式地址继续使用 api.koipage.xyz，不再经 Workers 转发或依赖 Supabase 托管数据库。
- 升级后请阅读新版告知并重新登录；账号、好友码和资料保留，分享开关恢复关闭，旧登录会话不迁移。

### 好友服务，统一访问入口

- 好友服务统一使用新的官方网络入口，启动时自动覆盖此前保存的服务地址，移除「连接设置」，避免误改后无法连接。
- 使用旧入口的账号需要重新登录，阅读并同意新版服务与隐私告知；切换后分享开关恢复关闭，游戏库、游玩记录和云端账号保留。
- 更新香港自托管、雨云基础设施、DNS 解析与迁移备份的相关告知。
- 调整网络请求超时，为读取请求增加一次重试；注册、登录及资料变更等请求不自动重复提交。
- 尚未确认结果的账号注销继续绑定原服务完成处理，避免切换入口后丢失注销进度。

### 开放注册，每个 IP 最多 5 个账号

- 取消邀请码要求与账号总量上限，可直接填写用户名、昵称和密码注册。
- 每个公网 IP 累计最多成功注册 5 个账号；失败不占名额，注销不会重置名额，用户名仍不可重复。
- 保留违规账号与网络封禁规则。

### 最近游玩与资料展示

- 优化个人主页最近游玩封面的获取方式，减少重复拉取完整公开游戏库；保留旧服务兼容处理与原有分享权限约束。
- 调整好友页、个人主页及相关提示，减少重复说明，让资料与操作更集中。

### 备份与日常操作

- 备份遇到已丢失的本地图片时，可跳过缺失图片并提示数量，避免单张图片丢失导致整份备份失败；只清理导出副本中的失效引用，原游戏库不受影响。权限错误和损坏图片仍会报告。
- 移除游戏右键菜单中的「打开游戏目录」。
- 修正原生全屏切换时可能出现的顶部留白，改善窗口显示。
- 精简设置、实用工具、资料刷新及部分页面的重复说明，保留必要提示与操作入口。
- 缩小公告中的加群区域，以紧凑提示保留群号、复制按钮和入群说明，减少对更新正文的占用。
- 移除好友页的加群提示，保留服务协议和隐私文档入口；同步原生程序与界面的协议版本，修复旧开发程序配合新版界面时反复提示同意协议的问题。
- 精简协议勾选区域上下的重复说明，详细内容通过协议入口查看。

### 升级与数据

覆盖安装继续使用原有游戏库、封面、分类、设置与游玩记录。原好友服务入口发生变化时需要重新登录；AI 密钥不包含在备份中，换电脑后需重新填写。
