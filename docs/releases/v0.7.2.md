# 恋页 KoiPage v0.7.2

首页最近游玩更紧凑，并补齐好友体验与同步修复。

- 首页默认显示最近 3 组作品摘要。同一作品连续游玩的记录继续归为一组，时间轴按需展开；查看全部在限高区域滚动，保留加载更早记录和作品历史入口。
- 好友支持最近 7 天游玩记录独立分享、自己的主页、昵称旁用户名、用户名或好友码搜索，以及确认后发送好友申请。头像选择收进弹窗，登录后收起加群提示。
- 游戏库后台自动同步；自己开启公开游戏库后才能查看他人收藏。断网保留登录状态，提示未连接并自动重试。
- 云端已补齐历史同步、主页、搜索、举报与账号注销接口。举报保存当时的封面证据，管理员强制关闭不能被后台同步重新开启。
- 注销失败保留登录凭据，成功响应丢失后可确认结果；旧会话失效时可重新验证原账号继续注销，删除目标始终锁定原账号。
- NSFW 和分级未知的公开来源封面保守打码。自定义封面作品暂不公开，封面审核本版不启用；本机封面、游戏库与存档不受影响。
- 一键资料焕新分别展示待确认和失败项，手动匹配完成后同步清理对应待处理状态。
- 支持无边框全屏：F11 切换，Esc 退出。注册前可离线阅读服务协议、隐私政策和跨境处理告知。

覆盖安装保留原有本机游戏库、游玩记录、存档和设置。账号注销仅删除好友账号及其云端关联数据，不删除本机游戏、资料或存档。

Windows x64 提供 EXE 和 MSI；已有版本可在「设置 → 关于」检查更新。`latest.json` 和 `.sig` 用于应用内更新，无需手动运行；源码压缩包供开发与审查使用。
