## 恋页 KoiPage v0.7.7

本次更新在 v0.7.6 的基础上加入 2DFan 攻略与关联作品、网络代理、库健康检查和游戏库键盘操作，并继续优化启动速度与日常浏览体验。以下仅列出相较于 v0.7.6 的新增与改进内容。

### 攻略与关联作品

- 游戏详情新增「攻略与关联」分区，与资料、路径和游玩历史并列。
- 「2DFan 攻略」会列出对应作品在 2DFan 的攻略帖，点开条目即可在详情页内阅读正文，支持段落、表格、图片和分页，也可以跳转到 2DFan 原帖。
- 未绑定作品时可以先搜索候选条目，确认后再绑定；已绑定的作品会在后台自动匹配并保存结果，下次打开不必重新匹配。
- 「关联作品」读取 VNDB 的关联条目，优先显示中文名并标出评分。已经在库中的作品可以直接跳转详情，其余在浏览器打开。
- 攻略与关联作品的结果都会缓存，再次打开很快。如果一直搜索失败，通常是 2DFan 在当前网络下无法直连，可以开启代理后再试。

### 网络代理

- 设置新增「网络代理」分区，可以填写代理地址、测试连接并随时开关，保存后立即生效，不需要重启。
- 支持 HTTP、HTTPS 与 SOCKS 代理；只填地址和端口时按 HTTP 处理。
- 开启后，资料匹配、攻略、AI 助手、Bangumi 同步和分享上传等所有对外请求都会走代理；关闭后完全直连。
- 代理只作用于恋页自己，不会改动 Windows 系统代理，也不影响浏览器、Steam 或其他游戏联网。
- 代理软件没有启动或端口不对时，报错会直接说明是代理的问题，设置页也会提示当前代理是否连得上。

### 库健康检查

- 设置 →「游戏路径」新增「库健康检查」，可以一次查出安装目录不存在、启动文件不存在、封面文件丢失和安装路径重复的作品。
- 结果会给出已检查、健康、已归档和需处理的数量，并列出具体条目；已归档的作品不参与检查。
- 检查只读，不会改动游戏库；需要修复时仍使用原有的「检查游戏路径」和「搬盘后批量修复」。

### 启动与加载更快

- 启动时先打开数据库再渲染界面，不再等数据库和迁移全部完成才显示窗口。
- 外观设置改为一次读取，主题、主题色、背景和玻璃外观同时应用，省去多次等待。
- 更新公告、更新对话框、生日庆祝、好友与 Bangumi 后台同步、AI 助手改为按需加载，首屏只带必要代码。
- 历史版本公告不再随启动一起打包，第一次打开公告时才读取。
- 游戏封面会生成缩略图供列表使用，详情页仍用原图；封面没有变化时启动不再逐个重新检查。
- 首页、游戏库和游戏文件夹共用同一份数据：进入软件时读取一次，来回切换不再重复载入，刷新时先保留当前内容再替换。

### 游戏库键盘操作

- 游戏库和文件夹页支持纯键盘操作：← / → 上一部 / 下一部，↑ / ↓ 按视觉行移动（网格一次跳一行，列表视图等同于上下一条），Page Up / Page Down 翻十部，Home / End 跳首尾。
- Enter 打开详情，L 按已保存的启动配置启动，F 收藏或取消收藏，X 多选这一部，Ctrl / Cmd + A 全选当前筛选结果（仅多选时），1–6 直接设置状态，Esc 退出多选或清除焦点。
- 按 `?` 或 F1，或点页头的「键盘」按钮，可随时查看这份快捷键说明。
- 焦点在输入框、下拉框或按钮上时不响应这些快捷键；全屏时 Esc 仍然只用于退出全屏。

### AI 助手可以批量改库

- 新增批量修改：一次把多部游戏的状态、收藏或标签改成一样，执行前列出受影响的游戏并等待确认。
- 新增资料搜索与写入：先搜候选条目，再按字段把资料写进游戏，同样先预览再确认。
- 新增文件夹与标签管理：可以新建、重命名、删除文件夹，把游戏放进或移出文件夹，也可以新建标签；删除文件夹只删分类，不动游戏和硬盘文件。
- 所有写操作只作用于本轮查询结果里出现过的游戏，伪造的 ID 会被拒绝。

### 好友

- 好友服务的文案与协议统一为正式版口径：注册不需要邀请码，错误提示和服务协议里不再出现内测说法。
- 好友页和个人主页的按钮、返回入口更明显；进入他人主页后的返回栏固定在顶部，不随滚动消失。
- 好友列表和邮件按账号暂存在内存中：离开再回来会先显示上次的内容，再在后台刷新；退出登录或登录失效时清除，不会串到其他账号。
- 邮件、好友主页和邮件面板适配浅色、深色和玻璃主题。

### 其他

- 启动游戏并登记游玩记录后，管理器会最小化到任务栏，不再压在全屏游戏上；游戏退出后不会自动弹回前台，仍可从任务栏或托盘恢复并停止游戏。
- 游戏库列表不再一次性读取每部游戏的完整简介、私人笔记和启动参数，首屏与筛选后的刷新明显更轻；详情页、资料匹配和 AI 读取全文时仍然取完整内容。
- 保留现有本地数据与登录状态；升级前仍建议在「设置 → 数据管理」中备份重要资料。
