## 恋页 KoiPage v0.4.0

这次更新加入游玩日历、首页时长图表和内置转区启动，同时整理作品详情的排版与导航。

### 首页游玩记录与时长图表

- 点击首页「最近游玩记录」可展开查看全部记录，展开和收起带动画，较早记录按需加载。
- 记录下方新增本日、本周、本月时长统计与可点击的图表。
- 统计按本地时间计算，跨午夜的记录分配到对应日期；时长在游戏退出并结算后刷新。

### 用日历回顾每天的游玩

- 点击时长区域的「日历回顾」，按月查看每天的游玩时长。
- 支持上一月、下一月、直接选择年月，以及返回本月。
- 点击日期，可查看当天游玩的作品及各自时长，并进入作品的游玩历史。
- 同时展示当月总时长、游玩天数与作品数；没有游玩的日期保留空白状态。

### 更紧凑的封面与详情排版

- 首页横向背景保持原始比例，左右两侧淡出；上方小封面条继续保持原有展示方式。
- 作品详情为横向、竖向封面分别排版，横向封面适当缩小。
- 详情导航固定显示，顺序为「基本信息 → 游玩历史 → 路径与启动 → 标签」，滑块随主题变化。
- 作品标题放大，状态选择放在收藏旁边，可随时修改并立即保存。
- 从游戏库进入详情、返回列表时均有过渡动画，返回后恢复列表的原滚动位置。

### 应用公告与版本公告

- 首次使用展示应用公告，可勾选「今后不再展示」。
- 更新后展示当前版本公告，可勾选「下次更新前不再展示」，后续版本仍会提醒。
- 两种公告均可在「设置 → 公告」重复查看并调整提醒选择。
- 公告底部提供 GitHub 项目地址，以及作者抖音昵称「空苍若叶」和抖音号「84398786679」。
- 公告随应用保存，无需联网即可阅读。

### 内置 Locale Emulator 转区启动

- 在「设置 → 启动设置」开启转区启动，默认使用内置 Locale Emulator 2.5.0.1，也可切换为其他转区工具。
- 内置配置采用日语代码页 932、日本时区，默认不请求管理员权限，无需单独安装资源管理器右键菜单。
- **内置 LE 只支持 32 位游戏 exe。** 64 位程序会显示不支持提示；不需要转区的游戏可关闭开关后直接启动。
- LE 使用游戏 exe 所在文件夹作为工作目录；使用内置 LE 时，单独填写的工作目录不会覆盖这一行为。
- 保留带空格、日文与引号的启动参数，等待游戏退出后结算时长，停止时一并结束转区启动的进程树。
- 第三方工具来源与许可说明随应用附带，详见项目的 Locale Emulator 集成说明。

### 安装与升级

适用于 **Windows x64**。EXE 与 MSI 安装包任选一种，运行需要 Microsoft WebView2。

沿用原有应用标识与数据位置，正常覆盖安装保留游戏库、标签、设置和游玩记录。建议升级前通过「设置 → 数据管理」备份数据库。
