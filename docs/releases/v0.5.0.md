## 恋页 KoiPage v0.5.0

本次加入实用工具页与内置 Magpie 窗口缩放，并更新托盘、扫描导入和资料标题语言设置。

### 实用工具与窗口缩放

- 在游戏库与标签管理之间新增「实用工具」，转区启动设置迁移至此。
- 内置 Magpie v0.12.1，无需另外安装；也可选择自己的 Magpie 程序。
- 支持查看 Magpie 版本和缩放快捷键、启动或退出工具，并可设置随游戏启动。
- 「功能介绍」可展开查看操作步骤、缩放算法与使用说明。
- 「缩放算法与滤镜」可查看本机配置的模式和效果链，并选择默认模式。Magpie 正在运行时先保存选择，下次启动时应用。
- 附带开发者调校的默认缩放配置，含「1k」等模式；首次使用且本机没有配置时自动初始化，已有配置不会被覆盖。
- 支持恢复内置默认配置，恢复前备份原配置；恢复时需先退出 Magpie。
- 游戏详情顶部新增「转区」「缩放」快捷开关，与实用工具中的全局启动设置同步。
- 随游戏启动只负责让 Magpie 运行；需要缩放画面时，仍需按页面显示的 Magpie 快捷键。

### 扫描导入与脚本启动

- 选择扫描目录前显示一次性整理提示，建议把 Galgame 集中存放，减少无关扫描；可选择今后不再展示。
- 扫描候选中提醒核对游戏名称与启动文件。
- 扫描和手动导入支持选择补丁提供的 `.bat` / `.cmd` 启动脚本，通过 Windows 命令解释器运行。
- 脚本若启动游戏后立即退出，游玩时长可能无法完整统计；脚本暂不支持转区启动。

### 资料匹配与标题语言

- 自动抓取优先选择中文标题，其次为日文原名，最后采用数据源标题；原名与游戏名相同时避免重复填写。
- 设置新增「资料匹配 → 标题语言」，可选择中文名优先、日文原名优先或数据源标题。
- 读取 VNDB 的官方简体／繁体中文标题，候选结果优先展示中文，没有中文时使用日文原名。
- 手动确认和一键导入时，中文／日文搜索名保持原样；英文搜索名改用匹配资料中的中文名或日文原名。
- 匹配时同时参考原名与英文别名，保留英文文件夹名称的匹配能力。

### 窗口与系统托盘

- 点击关闭按钮时，可选择缩小至托盘或直接关闭，并可记住选择。
- 托盘菜单提供显示恋页和退出入口，左键点击托盘图标可恢复窗口。
- 设置新增「窗口 → 关闭按钮行为」，支持每次询问、缩小至托盘和直接关闭。

### 安装与组件

适用于 Windows x64，EXE 与 MSI 安装包任选一种。沿用原应用标识和数据库位置，正常覆盖安装保留游戏库、标签、设置和游玩记录，建议升级前备份数据。

内置 Magpie 会增加安装包大小。Magpie 采用 GPL-3.0，Locale Emulator 采用 LGPL-3.0，均附带许可与来源说明。内置 LE 仍只支持 32 位游戏程序。
