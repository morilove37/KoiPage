## 恋页 KoiPage v0.6.5

这一页，整理好你的下一段故事。本次为 0.6 系列子版本更新，重点改善文件夹分类、游玩记录与公告体验。

### 文件夹，更顺手了

- 新增独立的「游戏文件夹」页面，内置社团与游玩状态分类。首页点击「游玩中」「已通关」「待开始」即可直达。
- 自建文件夹支持多级整理：先选择收纳子文件夹或直接添加游戏；只有游戏类型才显示筛选和游戏列表。空文件夹可重新选择类型。
- 父目录统计所有下级的游戏并去重。「管理游戏」可统一加入、移出，保存前显示变化数量。
- 支持文件夹拖拽排序、移动整棵目录，游戏也能单独或多选后拖入分类；最近一次拖拽或移动可在 8 秒内撤销。也可用「移动文件夹」选择目标位置。

### 游玩与显示修整

- 修复窄窗口列表中标题、标签和表头挤压，保留列宽并支持横向滚动。
- 文件夹标题直接显示当前名称；移除筛选区标签横排和导航数量小标，成功提示会自动收起。
- 在「游玩历史 → 补记游玩」新增大于 0 秒的记录后自动设为「游玩中」；补记 0 秒或修正已有历史记录时保留当前状态。

### 公告也整理了一下

- 交流群入口增加复制群号，申请前请阅读群介绍并正确回答其中的问题。
- 使用指引改成分区短说明，补充新分类入口、游玩记录操作和问题反馈建议。

覆盖安装沿用原有游戏库、分类、封面、设置和游玩记录。建议更新前在「设置 → 数据管理」备份；独立的存档快照目录仍需另行保留。
