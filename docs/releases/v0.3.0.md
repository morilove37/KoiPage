## 恋页 KoiPage v0.3.0

这次更新带来全新图标、主机式首页和游玩足迹分享。

### 新的恋页图标

采用《天津罪／アマツツミ》水无月萤的 Q 版头像，保留棕色短发、蓝眼睛、呆毛、红色发带和水手服的角色特征。应用内、桌面快捷方式、任务栏和安装包统一使用新图标。

### 像翻阅收藏一样切换游戏

- 首页上方提供游戏封面条，下方用大背景展示当前作品。
- 滚轮向上或向下切换游戏，首尾循环；选中封面、背景、名称和资料同步过渡。
- 支持点击封面、拖动浏览、键盘切换，以及随机抽取作品。
- 修复封面条到边缘后带动整个页面滚动、难以反向浏览的问题。

### 分享自己的 Galgame 足迹

在 **游戏库 → 分享足迹** 中生成游玩作品分享图：

- 按最近游玩、时长、评分、名称或发售日排序，支持升序与降序。
- 选择隐藏部分作品，或对指定作品使用统一替换封面；这些选择只影响本次分享。
- 每部作品展示名称、原名、评分、状态与累计游玩时长，列表支持原名搜索。
- 保存 PNG、复制图片到聊天软件；作品较多时自动分页，可保存全部图片。
- 显式点击 **生成24小时链接** 后，将当前图片上传至 beacon.host，生成可查看全部分享图的公开页面，约 24 小时后由服务方过期处理。服务有发布频率限制。

隐藏作品不会进入图片与汇总统计。仅生成链接时上传分享图；游戏数据库和本地文件路径不会作为资料上传。

### 下载与升级

适用于 **Windows x64**。下载 `setup.exe` 安装包即可，也可选择 MSI，两种格式任选一种。运行需要 Microsoft WebView2。

v0.2.1 用户可在 **设置 → 关于 → 检查更新** 中升级。继续使用原来的数据库位置，游戏库、标签、设置和游玩记录会保留。`latest.json` 与 `.sig` 是应用内更新文件，无需手动下载。
