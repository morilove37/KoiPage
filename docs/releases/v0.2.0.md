## 恋页 KoiPage：收藏相遇，续写下一页。

这是恋页的首次公开发布。一款面向本地 Galgame 与视觉小说收藏的 Windows 桌面管理器：把散落在磁盘中的游戏整理成可以浏览、筛选、启动和记录的游戏库。

### 从导入到继续游玩

- **添加游戏**：多选 exe 或扫描目录，确认名称和启动程序后，逐款核对资料，也可一键导入多款作品。
- **资料匹配**：接入 NextMoe、VNDB 和 Bangumi，补充封面、评分、标签、开发商和发售日；找不到时可手动填写。
- **回到故事**：首页以大封面展示上次游玩的作品，支持左右切换和随机挑选。
- **记录游玩**：查看累计时长、近期记录和单次游玩图表，管理收藏、待玩与通关状态。
- **离线标签汉化**：567 条内置译名，无需翻译服务；简介保留原文。
- **主题与壁纸**：浅色、深色、跟随系统及液态玻璃主题，壁纸只在液态玻璃主题出现。
- **应用内更新**：启动时自动检查，也可在「设置 → 关于」手动检查；确认后才下载安装，游戏运行时会阻止安装。

### 下载与安装

适用于 **Windows x64**。普通用户下载下面的 `setup.exe` 安装包即可；`msi` 是另一种安装格式，二选一即可。运行需要 Microsoft WebView2。

`latest.json` 和 `.sig` 文件用于应用内更新，无需手动下载。GitHub 自动附带的 `Source code` 是源码，不是可直接运行的应用。

### 已有本地旧版

旧版没有更新入口时，请手动安装本版本一次，之后即可接收后续版本提醒。游戏库、标签、游玩记录与设置继续使用原来的数据库位置。更新前可在「设置 → 数据管理」备份数据库。

### 数据与反馈

游戏资料来源于各数据提供方；恋页不提供游戏下载。游戏库保存在本机，离线标签汉化不会上传标签或简介。资料匹配、在线封面加载和版本检查需要网络。
