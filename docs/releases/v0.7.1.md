# 恋页 KoiPage v0.7.1

本版本为邀请内测构建，仅在本机交付，暂不发布 Release。

## 好友 Beta

- 新增独立账号、邀请码注册、好友码、好友申请、删除及屏蔽。
- 可主动分享正在游玩的作品和本次时长，支持隐身与隐藏指定作品，默认不分享。
- 每个公网 IP 仅可注册一个账号，注册失败不会占用名额；同一家庭或校园网可能共用公网 IP。
- 好友入口增加 Beta 标记，服务连接设置默认隐藏。
- 密码支持 12–72 位英文字母、数字或符号，不支持中文和空格。
- 进群可参与好友内测邀请码抽取。好友功能仅供测试使用，后续版本可能移除。

## 隐私与连接

- 登录令牌保存在 Windows 凭据管理器，在线心跳在后台执行。
- 不上传游戏路径、启动参数、私人备注、存档或完整游戏库。
- 加强旧登录失效、断网恢复、过期游玩状态删除及恢复备份后的隐私保护。
- 内测使用免费新加坡服务，国内不同网络的连通性在内测期间继续收集。

沿用原有游戏库、游玩记录、存档和安装升级标识。应用公告和版本公告均可在设置中重新查看。
