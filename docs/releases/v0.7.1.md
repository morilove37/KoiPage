# 恋页 KoiPage v0.7.1

## 好友 Beta

- 新增独立账号、邀请码注册、好友码、好友申请、删除及屏蔽。
- 可主动分享正在游玩的作品和本次时长，支持隐身与隐藏指定作品，默认不分享。
- 新增独立好友主页，点击好友头像、昵称或“查看主页”进入，查看在线状态、正在游玩作品和公开收藏。
- 新增可选择公开的游戏库，展示作品封面、游玩状态、两位小数个人评分和累计时长；支持名称/原名搜索、状态筛选、分页及公开收藏统计。
- 游戏库分享独立开关默认关闭，支持立即同步和单作隐藏；离线时仍可查看最后同步的公开收藏，断网或撤回失败会明确提示。
- 新增 18 款 Galgame 角色头像，可在“我的资料”中选择；本人、好友列表、申请和好友主页统一显示。
- 每个公网 IP 仅可注册一个账号，注册失败不会占用名额；同一家庭或校园网可能共用公网 IP。
- 好友入口增加 Beta 标记，服务连接设置默认隐藏。
- 密码支持 12–72 位英文字母、数字或符号，不支持中文和空格。
- 进群可参与好友内测邀请码抽取。好友功能仅供测试使用，后续版本可能移除。

## 隐私与连接

- 登录令牌保存在 Windows 凭据管理器，在线心跳在后台执行。
- 只有主动开启游戏库分享后，才同步允许公开的作品展示资料和小尺寸封面；不上传游戏路径、启动参数、私人备注、存档或游戏文件。
- 公开封面遵循自定义封面、裁剪和打码设置；隐藏作品同时从正在游玩和公开收藏排除。
- 删除或屏蔽好友后失去主页访问权限；关闭游戏库分享时撤回云端收藏，切换服务前先撤回旧连接的收藏。
- 修复旧数据库中整数评分（包括 0 分）导致游戏库同步中断的问题；个人评分保留两位小数，未评分单独显示。
- 加强旧登录失效、断网恢复、过期游玩状态删除及恢复备份后的隐私保护。
- 内测使用免费新加坡服务，国内不同网络的连通性在内测期间继续收集。

沿用原有游戏库、游玩记录、存档和安装升级标识。应用公告和版本公告均可在设置中重新查看。
