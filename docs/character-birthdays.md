# 首页角色生日

首页下方的「角色生日」展示今天及未来 30 天内游戏库主要角色的生日，今日寿星优先，最多直接展示三位。没有今日生日时展示未来 30 天内最近三位；没有符合日期的角色时显示明确空态。列表头像为 36×36，详情头像为 64×80。

首次点击「获取角色生日」后启用同步。之后进入首页、更新游戏列表、窗口聚焦时检查新增/过期作品；成功缓存 30 天，失败自动重试至少间隔一小时。同步串行限速，可取消，切页仍会继续，失败保留缓存。游戏有 VNDB ID 时使用 VNDB，否则使用 Bangumi；尚无外部 ID 的作品可从全部角色列表进入游戏详情匹配。

「全部角色」可以搜索全年角色，包括生日未知的角色；「已隐藏」可以恢复隐藏角色。角色详情支持显示名、生日、头像与隐藏状态的手动修正，自动同步不会覆盖修正；「恢复来源资料」清除修正，隐藏状态单独保留。日期只看本地月日，闰日平年在 3 月 1 日显示并注明，跨午夜或从托盘恢复时重新计算。

主要数据在 `birthday_characters`、`birthday_game_characters`、`birthday_sync` 三表中。头像位于应用数据目录的 `birthday-avatars` 下，文件按内容哈希缓存。仅展示主角/主要角色及非剧透关联；同源角色按外部 ID 去重，不进行跨站模糊合并。

全部角色弹窗提供生日专用 JSON 导入导出，包含头像字节、资料修正、隐藏状态和关联外部作品身份，不携带本机游戏路径。导入按当前游戏库的来源 ID 关联，覆盖文件中角色的修正，其他角色不受影响。单文件最大 64 MB，导出头像合计最大 12 MB，单头像最大 4 MB，最大尺寸 4096×4096；图片需实际解码成功。数据库备份保留生日表、修正与缓存路径；跨机器迁移头像使用生日 JSON，或另行保留头像缓存目录。

## 开发验证

```powershell
pnpm test:birthdays
node --test tests/*.test.mjs
pnpm build
pnpm check:ipc
cargo test --manifest-path src-tauri/Cargo.toml --lib --locked
```

日期测试包含 30 天范围的跨年边界；Rust 回归测试覆盖来源解析、多作品去重、关联 ID 变化、缓存保留、修正保留、取消时事务回滚、导入原子校验及四种头像格式。开发验证使用真实 IPC 迁移、同步与读写；隔离浏览器验证首次同步、多位寿星、未知生日修正、隐藏恢复、错误态和三种主题的 1280/960 布局。未进行安装包构建。
