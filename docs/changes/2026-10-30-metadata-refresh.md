# 一键资料焕新与自动补齐 Bangumi ID

设置 → 资料匹配新增「一键资料焕新」。按当前启用来源、默认来源和标题语言重新匹配已有游戏，适合修正旧版本导入的英文名和英文简介。

- 开始前显示覆盖警告并要求确认，先在应用配置目录的 `metadata-refresh-backups` 下生成 `.koibak` 资料库备份。备份包括数据库与本地图片，不额外打包存档快照；备份失败则不会更新资料。执行前需退出正在运行的游戏。
- 更新游戏名、原名、开发商、发售日、公共评分与简介，并合并标签。简介优先中文，中文版本中优先当前默认来源；无新内容的字段不清空，已有中文资料不会因仅取得英文结果而退回英文。
- 保留游戏路径、封面、游玩状态与时长、私人备注、存档、个人评分与短评、已有外部 ID。
- 只要启用 Bangumi 数据源，新游戏导入和资料焕新都会尝试补齐缺失的 Bangumi ID，不受默认源影响。借用简介时保留经过核对的 ID，即使主源已提供中文简介也会尝试缺失 ID 的匹配。匹配需唯一且精确，并核对发行日期与已知 ID；无法确定时留待手动确认。
- 刷新列表中「已更新」与「待确认」可能重叠：作品资料可以更新成功，Bangumi ID 仍需手动匹配。
- 每款作品在一个事务内更新；获取期间本地作品资料发生修改则跳过该款。中途停止不会撤销此前已更新的作品。进度与结果在当前应用进程中保留，离开设置页不影响任务。
- 焕新期间持有同步互斥锁，结束后通知 Bangumi 同步；已开启自动同步时，新绑定作品可能参与收藏同步。

验证：前端测试 122 项通过；Rust 单元测试 237 项通过、17 项按既有约定忽略；单独执行只读 VNDB → Bangumi 接口测试通过，核对中文简介与数字 Bangumi ID；前端构建、IPC 合约与版本一致性检查通过。测试数据库均为内存或临时数据库，未对真实游戏库执行焕新。
