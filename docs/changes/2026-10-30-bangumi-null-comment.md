# 修复 Bangumi 空短评导致同步中断

症状：点击双向同步后提示 `BGM_RESPONSE: Bangumi 返回的数据格式无效`，收藏同步尚未进入逐款处理就失败。

根因：Bangumi 收藏列表中的未填写短评可返回 JSON `null`，而原 `RemoteCollection.comment` 只接受字符串。`#[serde(default)]` 仅处理字段缺失，不处理显式 `null`。

修复：只对收藏短评的反序列化处理 `null`，统一转换为合并模型已使用的空字符串。保留正常字符串，仍拒绝数值、布尔等无效类型。收藏状态、评分、隐私及同步策略均不改变。

验证：

- 使用只读收藏接口确认响应结构及 `comment: null`，不记录令牌或个人短评，不执行远端写入。
- 新增列表和单条收藏的本地 HTTP 回归测试，修复前均复现相同报错，修复后通过。
- 检查缺失短评默认值、错误类型拒绝，以及评分、状态和隐私保留。
- Rust 全量测试 243 项通过、17 项忽略；前端构建、版本一致性和 IPC 检查通过。

修复不会自动开启同步或代替用户重试；旧错误提示会在后续同步成功后清除。
