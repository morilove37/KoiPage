# 确认界面选择简介来源

手动确认资料时，如同一作品取得多份有效简介，会显示「简介来源」下拉框。选项包含来源和语言，切换后同步更新简介预览、来源标注、署名和最终提交内容。初始优先中文简介，中文版本中再优先默认数据源；默认 VNDB 只有英文时也优先其他来源中文，没有中文时再使用默认源或原回退；只有一份简介时不显示额外选择器。用户手动选择后不会被默认源重置，直到重新选择作品或重新打开窗口。

切换不会修改其他资料字段或「简介」勾选状态，已有简介默认保持未勾选保护。重新搜索、选择作品或重新打开确认窗口时重置选择，旧请求结果不能覆盖当前作品。

后端保留合并前后所有非空的安全匹配简介，并去除相同来源、语言与文本的重复项。手动确认通过 `includeDescriptionChoices` 显式请求其他已启用来源；辅助请求并行、逐源 6 秒上限，失败时保留可用简介。自动补全和批量导入继续使用原来的默认回退路径，不为收集选项增加请求。

## 验证

- 前端测试：114 passed，涵盖中文优先、中文中的默认来源优先与缺失回退、切换文本/语言/来源、署名合并、无效选择、旧响应兼容和勾选状态保留。
- Rust 测试：199 passed，17 ignored（联网测试）。涵盖不被默认采用的简介仍保留、重复去除、禁用及主来源不重复请求。
- 专项只读联网测试：VNDB v4 手动详情同时返回 VNDB 英文和 Bangumi `zh-Hans` 简介，默认选中 Bangumi。
- 前端构建、IPC 合约、发布配置与 Rust 开发构建通过。独立复核没有发现新的问题。
- 不修改数据库结构，不自动更新已入库简介，不生成安装包。
- 实际开发版只读验证：默认源 VNDB 下初选鲲论坛中文简介；可切换 VNDB 英文、Bangumi 中文并同步预览，重新选择作品恢复初选；已有简介在切换前后均保持未勾选。前后游戏库统计一致，仍为 17 部，未保存测试记录。
