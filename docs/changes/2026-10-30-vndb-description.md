# VNDB 跨源中文简介

选择 VNDB 条目时，主来源和 VNDB 编号继续保留，简介可以采用其他已启用来源的中文文本。

1. 沿用 NextMoe 的 VNDB 外部编号反查，合并时允许中文简介替换英文简介。
2. 若仍缺少中文简介，依次尝试启用的 Bangumi、2DFan。每个补充来源最多等待 6 秒，包括搜索和详情读取。
3. 直接搜索只接受唯一的规范化标题精确匹配；同名歧义、FD/续作、已知外部编号或完整发售日期冲突均跳过。已有中文简介不被后续来源替换，空文本不覆盖有效简介。
4. 来源不可用、超时、停用或无法确认身份时，保留 VNDB 原简介。

确认页的详情和简介字段显示「简介来源」。已有游戏仍使用资料保护规则：简介默认不勾选，需要替换时用户主动勾选。新导入、逐款确认、批量导入和自动补全共用同一详情解析逻辑。来源标注用于确认预览，不新增数据库字段或修改既有简介。

## 验证

- 离线回归先验证旧逻辑无法替换英文简介及无法处理空白值，再验证修正后的中文优先、原条目身份保留、来源与署名一致。
- 候选测试覆盖唯一精确匹配、多个同名条目、FD/续作、原名匹配、重复搜索结果去重、编号及日期冲突。独立复核指出已知编号一致时仍需检查日期冲突，已补充回归并修复。
- 只读联网测试 `vndb_import_borrows_bangumi_intro_without_nextmoe`：仅启用 VNDB 与 Bangumi，读取 VNDB `v4`（CLANNAD），取得 Bangumi `zh-Hans` 简介（402 字符），保留 VNDB 主来源及编号。此测试直接调用资料解析函数，不连接或写入用户游戏库。
- 前端测试 108 项通过；Rust 常规测试 197 项通过、16 项联网测试跳过；上述专项联网测试另行执行通过。
- 前端构建、IPC 合约、发布配置检查与 Rust 开发构建通过；未生成安装包。
- 实际开发版只读预览：选择 VNDB `v4`，显示 `zh-Hans`、简介来源「鲲 Galgame 论坛」，新导入预览默认勾选简介；打开与关闭预览前后游戏库统计一致，仍为 17 部。仅查询和预览，未应用字段或创建游戏。

不保证所有作品都能找到其他来源的中文简介：辅助来源需在设置中启用，且必须有可确认属于同一作品的有效简介。
