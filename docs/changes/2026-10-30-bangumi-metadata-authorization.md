# Bangumi 简介焕新成功但 ID 待确认

问题：其他来源可以提供中文简介，但 Bangumi 资料请求始终匿名。Bangumi 会过滤匿名用户无权读取的成人条目，搜索可能只返回无关作品或衍生作；程序拒绝绑定这些结果，却将缺少授权的情况统一显示成待确认。

修复：

- Bangumi 资料搜索与详情读取复用 Windows 凭据管理器中保存的个人令牌，与收藏自动同步开关独立。无需开启自动同步即可使用授权资料查询。
- 搜索显式使用 `nsfw: null`，依据 v0 schema 保留所有当前账号可见结果；不设为 `true`，避免仅返回成人条目。
- 凭据只发送到官方 HTTPS API，禁用重定向，敏感请求头不进入调试输出，错误不回显服务器响应或令牌。
- 未配置令牌的焕新结果显示「需配置令牌」，并提示在设置验证保存后重试。保存了令牌但仍无唯一匹配的作品继续待确认。
- 设置说明令牌与资料查询的关系，修正同步面板中旧的「不会自动绑定」说明。

依据：[Bangumi 官方安全说明](https://github.com/bangumi/api/blob/master/open-api/api.yml)、[v0 搜索 schema](https://github.com/bangumi/api/blob/master/open-api/v0.yaml)。文档对 `nsfw` 的部分描述存在不一致；实测字符串 `include` 返回 HTTP 400，`null` 返回 HTTP 200，因此采用 schema 中的 `null`。

验证：前端 122 项通过；Rust 240 项通过、17 项忽略；前端构建与 IPC 检查通过。新增回归覆盖令牌请求头、敏感值保护、官方来源限制和搜索筛选参数。使用公开只读接口复现匿名搜索缺少对应本篇的结果。未使用真实个人令牌验证受限条目，未在用户游戏库执行焕新或收藏同步。
