# 未游玩自动同步为想玩

用户要求：本地「未游玩」在 Bangumi 同步中自动按「想玩」处理。

- `unplayed` 和 `wishlist` 都映射为 Bangumi 收藏类型 1；本地未游玩在同步确认后仍保留原分类。
- 已绑定且参与同步的作品，在远端没有收藏时创建想玩收藏；新收藏沿用当前隐私配置。
- 已建立基线且内容相同的再次同步不重复上传。未绑定及暂停作品继续跳过。
- 首次两边状态不同仍显示冲突，不直接将远端进度覆盖为想玩。
- 明确采用远端删除收藏时，在同一个事务内记录删除结果并暂停本款同步，防止下一轮又按想玩重建。用户重新开启该作同步后，才会再次参与处理。

测试使用内存数据库和模拟 API，覆盖首次创建、保留本地状态、重复同步、暂停与未绑定、既有远端进度冲突，以及接受删除后不重建。不会直接执行用户账号的同步，也不自动开启总开关。
