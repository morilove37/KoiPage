# Bangumi 双向自动同步（开发版）

新增设置中的个人令牌连接和双向自动开关；游戏详情新增独立个人评分、短评与条目绑定面板。通过 Windows 凭据管理器保存令牌，SQLite 迁移 4 保存个人记录、基线、冲突和版本号。

后台使用逐字段三方比较和请求前后复核，只同步已绑定游戏的状态/个人评分/短评。保护公共评分、私人备注、原有标签与隐私。默认新建收藏私密。备份恢复后自动关闭同步。

独立复核发现并修复账号切换误覆盖、旧界面暂停回写、详情状态不刷新、暂停期间继续上传、个人保存版本检查时机和失败前部分下载不刷新等问题，均补充回归或刷新逻辑。初始插入版本号由 0 改为 1，确保第一次下载之后也能拒绝下载前的旧表单。

验证包括完整前端/Rust 测试、IPC/发布配置检查、前端及 Rust 开发构建。HTTP 客户端使用本地 TCP 模拟服务器验证鉴权、分页、401/429、重定向拒绝及写入字段；同步引擎使用临时 SQLite 与假 API 验证拉取、上传、冲突、账号切换、失败基线、暂停及并发版本保护。凭据测试仅使用输入校验和随机不存在的测试目标，不写真实凭据。

最终结果：前端 119 passed；Rust 227 passed、17 ignored（联网测试）；前端构建、IPC 合约、发布配置与 Rust 开发构建通过。常规 `pnpm tauri dev --no-watch` 启动成功。实际库只读检查确认迁移 4 已应用，游戏数保持 17、个人同步表为空、自动同步未开启。

带远程调试端口的 GUI 验证启动被自动审批拒绝（仅返回 blocked by policy）。已改用无调试端口的常规开发启动；未声称完成该 GUI 自动化验证或真实令牌端到端验证。

未提供真实个人令牌，因此没有测试真实账号的登录成功、收藏写入或令牌落盘成功路径。实际用户库不导入测试作品，不运行带真实令牌的同步。首次使用需在设置输入有效令牌并显式开启同步。
