# 2026-10-22 外观、封面范围与搜索源

本次修改留在本地工作区，版本号仍为 0.6.3，未生成安装包、提交或发布。

## 玻璃外观

原有「图片不透明度」「背景模糊」只影响可选壁纸，未选图片时没有视觉作用，也不能控制玻璃面板。新增不依赖壁纸的「玻璃面板不透明度」（40–100%，默认 72%）和「玻璃磨砂强度」（0–60px，默认 24px），应用到卡片、侧栏、弹窗。100% 面板为不透明，默认底色改为深色以保持文字清晰。设置即时预览、串行保存并在启动时恢复；原壁纸控件注明作用范围，无壁纸时禁用。

持久化键：`glass_pane_opacity`、`glass_pane_blur`。

## 游戏库封面

详情页「框选游戏库封面」直接在原有大封面上覆盖选框，按原图真实尺寸保持 3:4 比例。可拖动移动、拖动右下角调整、选区外或 Shift 拖动重画；方向键移动、Esc 取消。显示游戏库预览，支持保存、取消、重置和恢复默认范围。

原图保持完整，仅游戏库网格卡片使用选区；打码设置仍生效。坐标保存在现有 `game_cover:<id>` JSON 的 `crop`，绑定图片路径。更换自定义图片会清除选区；完整备份恢复同步重映射选区路径。

## 搜索数据源

设置 → 资料匹配新增搜索源复选框，至少保留一个。默认源候选限制在启用范围；停用默认源后回退到首个启用源。新设置 `metadata_enabled_sources` 保存 JSON 数组；旧版未设置时保持全部启用，显式损坏/空值阻止请求并提示修复。

手动搜索等待设置加载，自动补全、批量导入和后端搜索均遵循启用范围。停用 NextMoe 后不再通过其补全其他来源的详情。
