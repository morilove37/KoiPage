# 压缩包解压

**实用工具 → 游戏解压**（实用工具第一位）支持把压缩包直接拖入，自动解压后在游戏库中扫描其中的启动文件。添加游戏对话框不再包含解压面板，导入仍走原有的「添加游戏」流程。

## 支持的格式

- `.zip`（含 `.z01`、`.z02` … 分卷）
- `.rar`（含 `.part1.rar`、`.part2.rar` 以及旧式 `.r00`、`.r01` … 分卷）
- `.7z`（含 `.7z.001`、`.7z.002` … 分卷）
- 分卷只需拖入任意一卷，程序会找到第一卷并交给 7-Zip 处理（例如拖入 `Game.part3.rar` 会自动使用 `Game.part1.rar`）。

## 解压目录

- 默认使用 **设置 → 扫描目录** 中的第一个启用目录；也可以点「更改目录…」临时更换。
- 每个压缩包解压到 `<目标目录>/<压缩包名>/`；同名目录已存在时自动使用 `名字 (2)`、`名字 (3)`。
- 解压失败会清理本次创建的目录，不留下半成品。

## 密码

- 加密压缩包会弹出手动输入密码的提示；输入正确后继续解压。
- 密码错误会提示重试；也可以「跳过」该压缩包，继续处理其余压缩包。
- 密码只在本次解压命令中使用，不会写入数据库或设置。

## 原压缩包清理

- 只有**解压成功**才会删除原压缩包；密码错误、解压失败或跳过时原文件保持不动。
- 删除的是整套分卷（例如 `Game.part1.rar` ~ `Game.partN.rar`、`Game.zip` + `.z01`、`Game.7z.001` 等），不会动同目录里名称相近的其他文件。
- 文件通过 Windows 回收站删除，**不是永久删除**；界面会提示「已移入回收站，如需恢复原文件请前往回收站还原」。
- 如果回收站操作失败（例如被系统策略禁用），解压结果仍然保留，界面会显示警告，原文件不会被强制删除。

## 解压后

- 点击「扫描解压出的启动文件并导入」会跳到游戏库，并自动打开「添加游戏」对话框、扫描刚才解压出的文件夹（深度 5），识别 exe / `.bat` / `.cmd` 启动文件并显示候选。
- 已存在的扫描结果不会被覆盖，解压出的候选会追加进来。
- 导入流程仍与原来一致：确认真实启动文件与游戏名，再进入资料匹配。

## 内置 7-Zip

- 应用内置官方 7-Zip 26.01 控制台版本（`7z.exe` + `7z.dll`），首次使用时释放到应用本地数据目录的 `tools/7zip/26.01`。
- 7-Zip 以 GNU LGPL 发布，RAR 解压代码受 unRAR restriction 约束；许可文本随包分发（`resources/7zip/License.txt`），应用只用于解压用户选择的压缩包，不实现 RAR 压缩器。
- 解压完全在本机进行，不会上传压缩包或密码。
